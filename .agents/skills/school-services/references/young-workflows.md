## 进入方式

用 `school_young_read_home` 读取首页或验证会话；已成功时不重复检查。失效按主 Skill 的既有授权恢复流程处理。浏览器预览用独立无头 Chrome context，复用 `school_mcp.young.session.load_session()` 的 storage state 和 user agent，不打印这些值。

从 `https://young.ustc.edu.cn/login/sc-wisdom-group-learning/dataAnalysis/visual` 打开首页。等待实际菜单出现后点顶栏，再点左侧子菜单；不要只等待固定秒数就判定为空。导航为单页应用，菜单 href 如 `/personalInformation/personalReport` 不是应直接拼到域名后的地址，应点击实际菜单并核对最终路径。出现同名父子菜单时使用可见链接角色与父菜单范围定位，不随意点第一个匹配。

## 标准任务步骤与停止点

报名与作品提交的前端路径、分支和结果核验要求已另存 [报名与作品提交路线](young-registration-submission.md)。该参考没有执行工具或真实提交验收，用户只问能力或暂停第二课堂时不启动报名。

**查本人学时/履职记录**：优先进入“个人成绩单”，确定用户所问学年，再读取对应本人记录。若进入“成绩查询”看到跨人员筛选，不搜索或导出他人信息。分开报告平台给出的德智体美劳、志愿服务、任职履职，不能把学生会职务自动计作公益学时。此次只核对表头，未读取或导出个人数值。

**找可参加活动**：进入“我要报名”后选择“报名中”，按 [项目分析流程](young-project-analysis.md) 读取列表、详情及系列场次，再核对正文中的资格、学时和实际完成条件。首次预览拦截的是默认培养方案的 `selectProgramme` POST，不代表报名列表不可读。现在已核对精确的查询路径，不能据此批量放行 POST 或执行报名、收藏、关注、签到、取消报名。

**准备奖项申请**：进入奖项列表，按用户所问奖项核对名称、当年通知、开放期、状态；如有只读详情，再核对实际条件和材料。团学奖项不一定等于本科专项奖学金，不凭名称混为一谈。只在本地整理材料，不新建、保存或提交。没有对应条目时说明当前列表和筛选范围，不推断全校没有该奖项。

**准备骨干述职**：进入个人申报列表，核对评议标题与考核区间。再根据用户提供的任职起止、职责、成果整理本地草稿；任期跨学年时按该次评议范围拆分。任职事实不等于已获学时、荣誉或评议结果。本次没有进入填写表单，必填项及附件规范待当次实际说明确认。停在新建/申报/上传之前。

**查看社会实践机会**：进入实践报名列表，按项目核对报名期、实践期、资格和状态。先说明所见入口与开放情况；不组队、不报名、不变更队伍。未验证项目详情或材料要求。

**了解场馆预约**：进入预约页，区分可预约列表与“我的预约”；仅查看入口和已有记录。可用时间、容量、审批或费用规则尚未实测，不能保证有位置。停在选择会占位的时段、发起预约或取消预约之前。

本次还看到了项目创建、项目审核、成绩申诉处理、预算管理、物资管理、一课学分申请等菜单，但未进入业务页。这些只记录为入口发现，不纳入已验证流程；不要因为账号能看见管理菜单就读取部门人员名单或执行审批。
