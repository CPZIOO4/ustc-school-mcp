# 课程、图书馆及辅助查询

## BB 课程学习入口

1. `school_bb_list_courses` 按用户所问学期/课程定位，不猜课程 ID。
2. `school_bb_read_course` 读取结果中的课程 ID，按实际菜单选公告、内容或资源。公告用 `school_bb_course_announcements`；受支持的只读页面用 `school_bb_read_page`，参数遵循工具定义。
3. 对“看看有哪些业务”，只进入菜单与工具列表，汇总名称和支持情况。2026-10-05 在一门课程中进入了公告、工具、小组、我的成绩、课程消息五页；课程之间菜单可能不同。
4. 对“找作业/资料”，只读受支持内容页中的说明、截止时间和文件链接。开始作答、创建尝试、上传作业、加入小组、发送课程消息、邮件和外部课堂激活不属于预览。下载文件需有对应用户请求，不能把链接当作下载成功。

本次小组、我的成绩、课程消息只验证页面标题/结构，后台动态请求被拦截；没有验证具体分数、小组名单或消息正文。“我的成绩”和“课程消息”路径尚不在现有 BB 读取白名单内，不编造调用成功，不修改白名单来完成预览。BB 成绩也不等于教务的学分绩点。

课程消息只打开文件夹列表，未打开单条消息，不能保证读取正文不会改变已读状态。仅为盘点功能时停在这里。工具菜单中的“发送电子邮件”和 Classin 入口没有执行。

### 日程表、联系人与讨论板（2026-10-06 补查）

已恢复 BB 登录并读取当前学期课程列表，再从一门课程的实时“工具”菜单进入以下三页。账号、课程 ID 和个人内容不写入 Skill；其他课程须重新检查菜单，不套用本次课程链接。

| 目的 | 标准路线与已见内容 | 停止点与证据边界 |
| --- | --- | --- |
| 查看课程日程 | 课程列表 → 目标课程 → 工具 → 日程表；页面有日/周/月、今天、上/下时段及创建事件控件 | 本次仅打开默认视图，未验证事件数据或切换视图。日程动态 POST 被拦截，不能把空白视图解释为没有安排。未创建事件，也未点击可能生成私人订阅地址的“获取外部日程表链接” |
| 找课程教师联系方式 | 课程列表 → 目标课程 → 工具 → 联系人 | 仅验证联系人页面可达，未提取或核实个人联系方式；不能保证每门课都维护联系人。不发邮件，不替用户联系教师 |
| 查看讨论入口 | 课程列表 → 目标课程 → 工具 → 讨论板；已见论坛与搜索相关界面 | 只到论坛列表层，不打开帖子、发帖、回复、订阅或标记已读。部分动态 POST 被拦截，未验证论坛记录完整性和帖子内容 |

实际导航路径分别为 `/webapps/calendar/viewCourse`、`/webapps/blackboard/execute/staffinfo/manageStaffInfo`、`/webapps/discussionboard/do/conference`，仅作定位记录。它们没有新增专用 MCP 读取能力；不要把这些路径当成可任意传给现有读取工具的白名单。需要完整读取时，应先核对动态请求的只读语义并补充适配，不能直接放行全部 POST。

## 图书馆

起点：`school_library_list_services` 返回当前公共服务目录，按名称选它实际返回的 URL。业务说明与外部业务系统分开核实；不要把图书馆统一身份登录直接推广到馆际互借供应商。

| 用户目的 | 流程 | 证据与停止点 |
| --- | --- | --- |
| 看借阅与到期 | 已授权连接有效后用 `school_library_list_loans`；需要历史才调用 `school_library_loan_history` | 读取能力在 2026-10-04 已验证，本轮不额外读取；历史仅限当前显示范围，不续借、不预约 |
| 找图书 | 目录 → 查找图书 → 核对书名/作者/ISBN 与所需版本 → 如实际检索页可用再查馆藏 | 本次只读说明页，发现 OPAC 与发现系统链接，未验证搜索或馆藏结果；无专用 MCP 检索工具 |
| 推荐购书 | 目录 → 文献荐购 → 读取当前说明与纸本/电子资源对应入口 → 本地整理目标书目信息 | 本次仅说明页；不发起荐购或打开可能创建流程的电子签章模板 |
| 文献传递/馆际互借 | 目录 → 文献传递与馆际互借 → 核对馆藏、文献类型、服务方式、费用/补贴及当前要求 → 整理书目与所需部分 | 发现多个外部平台链接但未登录；不提交订单、不充值、不承诺费用或到达时间 |
| 学位论文提交 | 目录 → 学位论文提交 → 读当前规范与提交系统入口 → 在本地检查用户指定文件 | 本次仅说明页，未登录提交系统；不上传、确认或自助打印 |
| 开放时间 | 目录 → 日常开放时间 → 区分馆区和公告日期 | 本次说明页可达；节假日以当次通知为准，不写死时间 |
| 学习空间预约 | 目录 → 学习空间预约 | 本次目录链接返回空白，业务系统未验证；不能假定等同青春科大场馆预约 |

## 跨平台辅助流程

**准备选课**：教务查本人课表/课程与培养方案入口 → `school_icourse_search_courses` 找同名课程 → 用返回 ID 读取课程及相关点评 → 区分官方安排、教师版本和社区意见。输出候选与冲突信息；不选退课。

**查申请通知**：`school_teach_list_categories` / `school_teach_search` → 从结果调用 `school_teach_read_article` → 核对通知年份、发布单位、报名对象、截止时间与附件链接。附件尚未读取就不能声称确认附件中的条件；外部表单不自动打开或提交。

**找学校邮件材料**：`school_mail_search` 按主题、发送方和日期缩小范围 → 使用返回的邮箱、UID、UIDVALIDITY 读取目标邮件 → 仅在用户要求时下载指定附件，不执行附件。不发送邮件或以回复联系办公室。本次盘点没有额外读取私人邮件。

**登录遇到二次验证**：复用主 Skill 的邮箱授权与恢复流程，让程序内部匹配验证码；不把验证码、Cookie 或客户端密码抄进业务流程。首次邮箱接入仍需用户本机获取客户端密码；网页自动创建尚未实现。

**找二手教材**：`school_nan7_search_offers` → `school_nan7_get_offer` 读取目标结果，报告标价、描述与页面状态。只查询，不联系、收藏、议价或购买。此为辅助生活服务，不是学校官方业务。
