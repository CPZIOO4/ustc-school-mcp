# 青春科大报名与作品提交：已识别路径

核对截至 2026-10-06。依据已读取的项目详情和学校网页前端代码，记录后续接入路线。**没有真实报名、上传或提交验证；没有对应执行 MCP 工具。** 当前只执行读取、筛选和本地材料准备。用户尚未选择要报名的项目时，到候选信息结束，不自行报名测试。

## 路由与证据等级

| 阶段 | 已知情况 | 验证状态 |
| --- | --- | --- |
| 查项目、读详情、展开系列场次 | 见 [项目分析](young-project-analysis.md) | 真实只读请求成功 |
| 普通报名 | 前端确认后向具体项目提交报名请求 | 只核对代码，未提交 |
| 需报名信息 | 先显示报名信息表，校验后提交 | 已识别表单逻辑，未打开并填写真实表单 |
| 作品入口 | 根据项目形式、可提交标志、已有作品状态显示提交/编辑/查看 | 只核对前端逻辑；个人入口需当次确认 |
| 附件上传、作品保存 | 选择文件后上传，再提交作品名称和附件引用 | 均未执行 |
| 报名结果、作品结果 | 应独立查询或重新进入本人记录核验 | 完整执行链未验证，不声称已跑通 |

## 报名前准备

输入为用户指定的项目/具体场次，或明确的筛选条件和选择范围。系列项目必须定位具体子项目。先核对当次状态、报名窗口、资格、时间地点、名额、重复报名、外部报名依赖和不可取消等提示。缺失重要条件时报告缺口，不把“看得到”当成“符合资格”。

需要额外报名资料时，前端支持院系、班级、手机、邮箱和自定义项；具体要求随项目配置变化。不得用别的项目表单代替当前项目，也不默认把任意本机个人信息交给组织方。已有用户明确提供的有效信息可复用，未知必填信息再询问。

前端分支包括作品类报名提示、不可取消提示和线上参与不计学时提示。保留其业务含义，不把所有弹窗统一当作可以点击的确认框。未来实现时，用户明确授权的报名无需机械重复确认；有未涵盖的额外承诺、费用或未知必填项时先说明具体问题。

## 作品准备与提交边界

1. 根据真实项目/场次确认本人报名状态、作品提交期与可提交状态。读取允许扩展名、标题要求、作品内容和证明要求；需要时参考 [项目分析](young-project-analysis.md) 区分原创作品、参赛证明、打卡记录与外部投稿证明。
2. 只对用户指定的本地文件做格式、数量、大小、可打开性、标题和内容完整性检查。未知材料不编造，不能把生成内容作为真实参加、签到、训练或原创完成的证明。
3. 前端已见作品名称必填且最多 100 字，附件界面最多 10 个；允许格式来自项目 `attaType`。这些是当时前端约束，正式接入前仍需核对实际表单及服务端限制，不给所有项目写死文件格式或大小。
4. **选择文件会立即向服务器上传，即使尚未点击最终提交。** 只读预览必须停在文件选择之前；“上传后再让用户决定”不属于纯本地准备。
5. 后续执行若已得到该项目及文件的上传提交授权，应先确认上传成功，再提交标题与附件引用。需要额外重要信息时，在上传前说明。编辑已有作品涉及替换原记录，不能把新增提交的授权自动扩展为覆盖旧作品。
6. 结果核验须分开记录“附件上传成功”“作品提交成功”“审核状态”“学时状态”。上传成功不等于作品已提交；作品已提交不等于审核通过或学时到账。

## 给后续实现者的已观察路径

以下相对 `https://young.ustc.edu.cn/login/wisdom-group-learning-bg`。写路径只作为技术记录，**不是可在预览中调用的读取白名单**。

| 方法与路径 | 前端用途 |
| --- | --- |
| `POST /item/scItemRegistration/enter/{itemId}` | 普通报名，或携带报名表字段报名 |
| 上传至 `/item/scItemWorks/uploadItemWork?itemId=...` | 文件选择后立即上传附件 |
| `POST /item/scItemWorks/add` | 提交/编辑作品，携带作品名称、项目及附件引用 |
| `GET /item/scItemWorks/queryByItemId/{itemId}` | 前端编辑时读取已有作品附件；尚未实际调用核验 |

所有标识来自可见项目或本人记录，不构造他人标识。接口名、字段和页面权限可能变化；正式适配应先核对当前页面，分别实现读取、上传、提交、结果查询，不把任意 URL 或任意请求体交给弱模型执行。

## 固定停止与恢复分支

| 情况 | 后续行为 |
| --- | --- |
| 未指定项目/场次，也未授权按条件选择 | 只给候选或说明，停止真实报名 |
| 没有对应实现或真实验证 | 报告当前证据等级，不使用“已跑通” |
| 报名后超时、响应不明 | 先核验本人报名记录，不立即重复提交；无法核验则结果未知 |
| 上传失败或只有部分附件成功 | 不提交不完整作品；报告已上传范围，不能假定关闭窗口会删除服务端文件 |
| 上传成功但作品保存结果不明 | 先查看已有作品，核对标题与附件，不盲目重新上传或覆盖 |
| 需要外部报名/群内操作 | 明确尚未完成的外部步骤，不代发消息、不声称全流程完成 |
| 已提交且状态待审核 | 说明已提交、待审核；不报告已获学时 |

未来真实验收使用用户确实要参加的活动及其指定材料；当前没有这样的目标，不用任意活动或虚构作品试提交。
