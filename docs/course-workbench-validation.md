# 课程工作台与作业任务管理

实现入口为原生桌面客户端。首页保留对话与常用操作，侧栏增加「课程工作台」与「作业任务」。

## 功能

- 课程支持搜索、学期筛选和置顶；详情包含概览、作业、材料、通知，以及与已缓存教务课表的人工关联。
- 更新课程列表与更新单门课程分开执行。单门课程读取 BB 主页、作业目录和通知，部分失败时保留成功内容和上次快照。材料目录按已读取的同课程链接逐层展开，并保留已读目录。
- 作业支持待处理、已完成、归档及课程筛选；展示原始要求、来源、截止时间和要求变化。个人进度、计划时间、备注与有来源的交付清单独立保存。
- 手动任务支持新建、编辑、归档与恢复。任务可创建关联日程，设置提前提醒，并从任务返回日程详情；提醒依赖应用运行。
- 平台提交记录使用独立字段，需点击核实后读取学校记录；个人任务标为已完成不会修改学校提交状态。
- 课程和任务详情均可打开右侧助手。当前对象由后端读取并传入模型，相关对话可重新打开。助手使用 `school_workspace` 先查询、再提出个人清单或进度的变更，沿用现有办理许可流程。
- 普通读取、筛选、保存及日程操作直接调用本地接口，不经过模型。模型用于理解材料、整理清单和回答问题。

## 数据与实现

`native/core/src/workbench.rs` 负责账户绑定的加密存储、远端事实合并、版本冲突检查和模型工具。个人文件位于应用 profile 下的 `course-workbench.dpapi`，不进入分发包。后台刷新保留个人字段，账号变更后拒绝保存旧请求。

`study_read` 是现有 BB Python 业务读取的固定兼容适配器；Rust 桌面后端控制读取范围和落盘。此部分尚未迁移为纯 Rust。课程目录的分页和正文读取有上限，界面显示截取状态；附件通过现有原网站下载和助手材料上传入口使用。完整数字日期才转换成排序时间，其他时间保留原文。
