# 课表、历史作业与追问流程验收

日期：2026-10-22。运行环境：Windows 原生 Tauri/WebView2、Rust IPC、学校大模型平台的 deepseek-flash。使用本人授权的隔离录制配置和真实教务、BB 会话。查询目标固定为 2026-10-22 的课程及两项 2026 春季历史作业。

## 实现

- 增加固定只读工具 `school_study_query`：一次处理日期课表、课程定位、作业定位、截止与历史提交核实；全部学校读取继续通过既有任务归属、连接检查和工具目录校验。
- 重名、目录截断返回候选；精确匹配优先，停止后不继续下一步。作业目录参数限制为 max_pages=15、limit=50。
- 每轮记录连接、工具、模型和总耗时；模型记录请求大小、消息数、响应头、首块、首正文、首工具及总耗时。计时数据不包含密钥和推理正文。
- 已结束轮次的推理内容从后续模型输入中移除；保留用户消息、答案、业务回执和完整链接。当前工具轮次的推理字段继续满足服务商协议。
- 核实成功的作业链接保存到对话 `source_links`，界面独立显示入口。追问改写沿用已有事实，避免再次查询学校。
- 原生统一身份登录允许学校 SSO 实际使用的 analytics 网关精确路径；仅 HTTPS、GET、主文档，其他路径、XHR、POST 继续拒绝。浏览器导航失败保留净化后的网络错误码，便于区分连接失败与登录失效。
- 学习安排根据已查课程和历史作业给出时间块；未读取的附件不用于生成具体题目、算法或软件要求。
