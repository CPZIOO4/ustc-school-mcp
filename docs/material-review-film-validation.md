# 作业材料复习镜头验证

2026-10-22，在真实 Tauri/WebView2 客户端与 Rust IPC 路径完成：从本人 BB 提交记录下载 PDF，使用“添加材料”加入对话，连续输入要求，由当前配置模型调用材料读取工具后生成复习重点与自测题。

## 实际流程

- 沿用获授权的专用录制配置和本人 BB 会话；原生网页直接显示提交记录，下载操作成功。
- 下载文件与添加材料后保存的文件 SHA-256 一致。
- 正式录制的读取回执覆盖第 1–3 页及第 4–5 页，各段 `selection_complete=true`，没有剩余字符偏移。模型随后生成正文。
- 本轮真实调用从发送到结束约 35.75 秒，首次正文约 31.02 秒。影片压缩等待及生成时间，保留输入、思考、逐步生成的顺序。
- 录制没有提交或修改学校作业，原有两项复习日程保持原样。

## 界面改进

用户消息中的材料展示为文件名标签，减少本机完整路径对阅读的干扰。原始消息、模型上下文及文件授权路径保留。仅格式匹配的材料附录会转换；普通文本保持原样。通过原生页面核对单附件、多个附件及普通文本，页面无脚本错误。开发宿主重新构建并实录；本轮未制作新的安装包。

## 影片范围

第五镜头 14 秒，接在前四段 45.5 秒后，合计 59.5 秒。网页、输入及回答来自实际客户端；纸页使用实际下载 PDF 的第一页面内容。纸页展开和前后层次移动是剪辑动效，不表示应用已提供该种文件预览动画。系统光标素材用于引导真实操作位置，文件选择等待经过剪辑。影片保留“添加材料”动作及文件名标签。

私有录制、原始回执、页面图像和验证脚本位于 `.local/video-shot5/`，不纳入源码发布包。
