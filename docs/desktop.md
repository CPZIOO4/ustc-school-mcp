# 本机学校助手（Windows）

另有 [Rust + Tauri 原生客户端](native-desktop.md)，使用独立窗口并沿用相同数据目录。下文描述浏览器版；原生版的构建、退出行为与平台限制以原生客户端说明为准。

在不安装 AI 客户端、不手写 MCP 配置的情况下，用自己的模型 API 处理已有学校业务。双击 EXE 后在浏览器打开本机界面；后端仅监听 `127.0.0.1`，不部署公共网站。原来的 MCP、协调入口和命令行用法继续保留，新增六个可选 MCP（五个登录业务平台和公开网页读取）。

当前界面采用已批准的蓝白校园方案：对话、账号连接、任务记录和模型设置共用统一的导航、状态与操作组件。真实官方登录、邮箱绑定和用户模型验收仍需本人参与。

首页采用“对话＋常用操作”，可直接查看课表，或从 BB 作业、校园信息开始准备指令。切换对话会保留各自尚未发送的文字和材料；这些草稿仅保留在本次应用运行期间，退出应用后不保留。已发送对话、模型配置与课表快照仍按原流程加密保存。任务处理中切换到其他页面时，顶部仍可查看进度并停止后续步骤；停止不代表已发出的学校请求被撤销，需核对原回执。

## 界面

新增“校园网站”“我的课表”“个人资料”三个直接操作页面，不需要配置模型。校园网站可搜索17个固定入口，点击在浏览器新标签页打开原站；不内嵌网页，不转移助手后台Cookie，原站使用浏览器自身的登录状态。公开导航不要求学校登录，个人页仍需要应用登录。

课表页通过已有教务读取代码刷新当前或所选学期，在本机加密保存一份带更新时间的快照，按周筛选不联网、不调用模型。刷新失败保留上次成功快照并提示；未明确周次或星期的安排不丢弃、不推算，自定义日期及教学分组保留核对提醒。主页的“查看课表”也直接进入此页。

个人资料包括姓名、院系、专业、入学年月、邮箱、电话和校内住址，由本人填写，未知项留空。资料与当前账号绑定，用Windows DPAPI加密，保存时校验字段与版本以防覆盖其他窗口的更新；不会修改学校记录，也不自动注入模型对话或申请表。账号栏仅表示本机已绑定的学校账号，不代表此次又向学校核验了身份。锁定或切换账号会清除页面上显示的私密数据。

对话页使用主区域全部宽度，侧栏只保留导航、历史对话与账号状态。手机宽度采用顶部分页导航和“最近对话”入口。首次使用的两步状态、十四站连接卡片、任务表格与回执、处理中或中断提示、具体操作确认均来自真实本机接口；任务状态使用中文显示。没有增加图书馆续借、自动财务提交等尚未实现的业务。

按钮、文字、表单与图标为原生 HTML/CSS/SVG，不依赖外部字体或 CDN。

授权仍仅覆盖本条指令或具体待确认操作，切换或新建对话时清除未提交的办理许可。文件可从待发送材料中移除；切换对话时不把迟到的上传结果带到新对话。退出、解绑和清除使用可取消的本机确认框；接口授权、会话隔离和未知写入防重发沿用原后端。

## 首次使用

1. 完整解压 `USTC-School-Agent-Windows.zip`。保留 `_internal` 文件夹，双击 `USTC-School-Agent.exe`。需要本机 Google Chrome，程序已包含 Python 和运行依赖。
2. 点击“学校身份”，在学校官方窗口输入账号密码并完成验证。程序只记录登录中观察到的账号，以及经 BB 连接核实的会话和实际设备信任，不记录学校密码。身份过期后从“账号与连接”重新验证。
3. 在“模型与设置”选择 DeepSeek，填写 API Key，点击“保存并测试”。官方地址和推荐模型已填好；也可选择“自定义兼容 API”，填写其他服务商地址与模型。可获取模型列表，或手工输入；粘贴完整 `/chat/completions` 地址时自动转为基础地址。本机模型允许 localhost HTTP，远程地址须 HTTPS。测试会实际验证工具调用及读取返回结果，失败时显示可操作原因。
4. 点击“开始对话”，直接描述事务。程序在当前任务第一次访问平台前检查连接，必要时复用统一身份会话后台恢复；超时、限流或权限不足不会触发反复登录。需要本人验证时显示重新登录入口，原对话和任务保留，完成后继续原任务。查询与准备默认可执行，发送、提交、报名或发布仍遵循本条指令或具体操作的授权。
5. 邮箱可稍后在账号页绑定，未绑定不妨碍其他学校业务。本人登录邮箱后，程序按确认授权创建客户端密码、加密保存并核实 IMAP；有可用配置时不重复创建。评课社区发表使用独立账号，需要时单独登录。

各平台卡片都有对应登录入口（教务处公开通知无需登录）。BB、教务、青春科大、财务、图书馆、南七集市先检查已有会话，有效时不再打开登录窗口；失效后“登录 / 验证”打开对应官方页面。本人操作的登录窗口可见，平常办理仍使用后台 Chrome。站点会话分别保存，统一认证的有效设备状态共享。重新打开应用不清除这些记录，但“已保存”不表示已联网确认；平台过期、撤销会话或变更验证要求后仍须本人重新验证，不能保证永久免登录。

邮件附件和导出文件完成后会在原对话显示下载按钮，也可按用户要求继续用于该对话内的发信或作业材料。下载按对话中的文件标识取回，不能输入任意本机路径。后续使用核对摘要，文件被修改后必须重新获取。

模型可直接读取本对话上传或工具取得的文本材料，支持 TXT、Markdown、CSV、TSV、JSON、YAML、LOG、XML、TEX，以及 DOCX 正文和表格文字；只读取文字，不还原文档排版。每个材料最多 8 MiB、50 万字符，单次返回最多 12,000 字符，余下部分按返回偏移继续读取。PDF、图片/OCR、旧 DOC、XLSX 暂未接入，不能把“上传成功”理解为“模型已读懂”。这些文件仍可作为获准提交的原始附件。读取工具不会执行文件、展开压缩包到磁盘或跟随文档外链，也不能读取其他对话文件或本机凭据。

兼容范围为支持工具调用的 Chat Completions API，并不代表所有厂商的原生协议。模型列表可用不等于业务能力合格，需以本机测试与真实任务核验为准。DeepSeek 预设与模型名依据[官方接口文档](https://api-docs.deepseek.com/)；模型列表来自用户配置的服务商接口。

## 已批准范围与当前实现

| 项目 | 实现及边界 |
| --- | --- |
| EXE 与本机页面 | 引导、聊天、账号、模型配置、任务记录；不需要用户安装 Python |
| 官方登录 | 用户操作官方 Chrome 登录窗口，程序不保存统一身份密码 |
| 会话与设备信任 | DPAPI 加密，按账号恢复；失效明确停下 |
| 分站连接 | 按任务自动检查连接，六站按需后台恢复，评课发表需独立登录 |
| 邮箱自动绑定 | 复用原有一次生成、捕获、加密、IMAP 检查及中断恢复流程 |
| 邮件验证 | 单独选择启用；只读取当前验证挑战的新邮件 |
| 模型接入 | DeepSeek 预设或自定义兼容 API；获取模型列表、保存并测试工具调用及读取结果，失败不自动重试请求 |
| 聊天智能体 | 原协调工具和 Skill 按任务加载，24 步上限，串行执行 |
| 材料阅读 | 当前对话文本与 DOCX 提取、分段读取、已获附件的摘要复核；不支持 OCR |
| 授权与预览 | 界面许可与模型参数分离，准确操作确认，已有本条许可不重复问 |
| 任务及恢复 | 加密聊天和回执；重启保留；未知写入不重放 |
| 账号管理 | 退出登录、解绑、切换账号、清除；运行中或结果未核实的后台写入先处理 |
| 打包与验证 | 包含资源的 Windows 文件夹包；合成完整界面与 EXE 验证，真实登录/API 单独记录 |

## 本机数据和任务

默认数据在 `%LOCALAPPDATA%\USTCSchoolAgent`，与原 MCP 的 `.local` 分开。

- `profile` 保存这个学校账号的站点会话、聊天、任务及附件。Cookie、凭据、聊天和业务数据库中的私密内容使用当前 Windows 用户的 DPAPI 加密；用户选择的材料和原工具下载文件仍是私人目录中的普通文件。
- 模型配置在该目录的加密文件中。更换 API 地址必须重新输入密钥，防止旧密钥被带给另一家服务。API 请求不跟随跳转。
- 切换学校账号清除原账号数据，保留模型配置；清除全部则连模型配置一起删除。解绑邮箱不在官网撤销已有客户端密码。尚未完成的创建记录只去掉暂存秘密，保留防重复标记。
- 退出登录锁住界面数据访问；重新验证原账号后可继续。关闭浏览器标签页不等于退出后端。用设置里的“退出应用”结束本机服务；已安排的独立后台任务按各自规则继续。
- 一次只办理一轮操作。“停止后续步骤”不撤销已经发出的请求或已安排的后台任务。恢复先核实业务原记录，不能把“已安排”理解为“已提交成功”。

后端在模型响应返回后、工具实际分派前再次检查停止请求；迟到响应不能启动新的操作。模型一次提出多项调用时保留完整记录，只处理第一项，其余明确返回 `not_executed`，再由模型根据真实结果决定下一步。截断响应、错误参数 JSON、重复参数名和非有限数值在进入历史与执行前拦下。

重启恢复按每一批工具调用补齐未返回记录，即使模型重复使用调用 ID，也不会误把旧回执当成新回执。外层操作状态区分 `completed`、`interrupted`、`stopped` 和 `waiting_for_approval`；对话结束不推断学校业务成功。模型超时、限流、认证失败和格式错误提供固定错误码，不回传服务商错误正文，也不自动重复请求。再次测试模型失败会取消旧的“测试通过”标记。

业务失败沿用明确的异常类型和错误码，不根据报错文字猜测是否掉线。协调器、聊天记录和连接检查返回 `error_code`、`next_step`、`recovery`；冷却时保留 `retry_after_seconds`。认证失效才提示恢复登录，403 权限不足、超时、网络故障和后台运行故障分别处理。无法判断的错误报告未取得可靠结果，不伪装为空查询。工具失败后本轮停下；已分派的写操作结果不明时，先查原回执并继续拦截重复写入。

每次模型请求按 UTF-8 请求体 192,000 字节整理上下文，不额外调用模型生成摘要。超限时保留全部用户原话，以及精确任务目标、文件清单、非只读调用参数、原授权记录、业务回执和查询入口；较早的助手说明与查询正文按完整调用批次移出本次请求，最近可容纳的批次保留。完整聊天仍加密保存在本机，不修改原文。整理后的任务须先用 `school_agent_task(include_context=true)` 完整恢复，才能继续准备或办理；历史授权不会变成新授权。

这个字节预算不是模型 token 数保证，不代表支持无限对话。本机单对话仍有 8 MiB 记录上限；若连必须保留的用户要求和任务凭证都超过请求预算，会明确停止，不静默丢弃。不同模型的真实上下文上限仍需用用户配置的 API 验收。

本机接口同时检查随机访问令牌、Host 和请求 Origin。令牌放在启动链接片段中，界面随后移除片段；不记录访问日志。清除动作核对应用专用目录，拒绝把任意现有文件夹当应用数据目录。模型没有通用 shell 或浏览器执行器；提交材料只能来自该对话选择的文件或已授权工具在该对话获取并核验的附件。

## 开发、打包、验证

源码启动：

```powershell
.venv/Scripts/python.exe -m school_mcp.desktop.server
```

隔离开发可加 `--data-dir <空目录> --no-open`。不得把已有私人 MCP 目录作为应用根目录。离线检查可用 `--self-check`，在该目录生成无账号内容的 `runtime-check.json`，检查打包 Skill、真实工具 schema 和无头 Chrome，不访问学校。

```powershell
./packaging/build.ps1
.venv/Scripts/python.exe -m unittest discover -s tests -p 'test_*.py'
.venv/Scripts/python.exe tests/smoke_desktop.py
.venv/Scripts/python.exe tests/smoke_desktop.py --exe dist/USTC-School-Agent/USTC-School-Agent.exe
```

构建由锁定的 build 依赖组提供 PyInstaller。spec 仅列入源码资源、Skill、依赖和运行元数据；不会复制 `.local` 或应用数据目录。生成目录 `dist/USTC-School-Agent` 及 ZIP 都被 Git 忽略；发布二进制时使用该专用包，不能压缩整个开发目录。

合成界面验收使用一次性账号目录和本机假模型 API，调用真实财务离线预检，并检查任务、第二次启动、重启恢复、小屏布局、JS 错误和打包后台 worker。它不证明真实学校登录、邮件密钥创建或特定商业模型已验收；这些需要本人在界面完成后另记证据。

## 扩展能力（2026-10-12）

模型设置可选“科大大模型公共服务”，登录学校身份后获取本人已有密钥、选择其可用模型并测试绑定，不要求将密钥复制到对话，也不会创建项目或申请额度。无已有密钥时仍须先在学校官方平台申请。

材料支持 PDF、图片本地 OCR、Excel、文本和 DOCX；结果可以生成可下载的文档或表格。按页和工作表限制读取范围；扫描识别可能错字，表格公式缓存不代表重新计算。

一网通办提供服务目录、待办和申请进度；学工提供奖学金条件、申请/获奖记录和优秀学生奖学金授权申请。申请先收集资料、生成完整预览，再由固定工具填写、保存、重读核对、提交并回查；表单打开就会建草稿，其他模板与附件暂不适配。西区图书馆提供空间查询及预约计划；云盘支持指定目录上传、下载、移动和新建文件夹；Vlab 支持本人虚拟机环境检查、材料传输、授权命令和结果取回。提交前核对具体计划；结果未知只读回查。中区/高新区空间、财务提交、选退课、第二课堂作品提交仍不在已实现范围，详见 functional-coverage.md。

## 安全日志与故障反馈

模型与设置页可以查看错误编号、复制摘要、预览导出报告、清理诊断日志。不会自动上传；清理不影响业务回执。记录范围和启动失败时的离线导出见 [安全日志说明](safety-logs.md)。


## 原生应用内网页标签（开发版）

聊天回复和校园导航中的 HTTPS 链接在顶部网页标签中打开，保留“学校助手”页，支持返回聊天、标签切换、关闭、前进、后退和刷新。最多同时保留 10 个网页。远程网页在独立子 WebView 中运行，不能调用本地模型配置、文件或学校业务 IPC。

原生宿主按当前应用账号读取已绑定站点的加密 Cookie 和 localStorage，并交给浏览器对应的域／来源；统一身份共享记录只取 CAS 来源，不把 BB 会话跨服务导入。浏览器使用本机独立缓存，导入标记与临时 Cookie 保持相同生命周期：同一浏览器会话中不重复覆盖网站状态；关闭最后一个网页或重开应用而产生新浏览器会话时，重新继承应用绑定的会话。网站当前会话内的退出保持有效，学校账号整体退出请使用应用账号页。锁定关闭网页，清除账号后使用新的浏览器数据代次。模型密钥不参与网页登录。

会话复用不等于所有网站免登录：学校撤销会话、二次验证、只存在 IndexedDB 的设备证明，以及未适配的独立账号仍可能要求官方登录。邮箱客户端密码也不等同于网页版邮箱会话。当前未把网页里新登录后的会话反向同步到业务工具。2026-10-23发布包已包含网页标签，并通过107官方页面的登录态继承验收。

## 107 算力任务

可在对话中查询本人107计算作业的状态、排队与运行时间、CPU/GPU和内存分配，例如“查107作业 a-relation021，给我完成状态、耗时和分配资源”。默认查询最近7天，也可指定作业编号和1–31天范围。资源概览展示共享集群的实时状态。

“账号与连接”中提供107连接检查，“校园网站”中保留官方入口。查询复用本人统一身份，来源可在应用网页标签中打开。账号失效时使用该卡片的“打开验证窗口”恢复统一身份，再检查连接。提交、取消作业和Shell操作在107官方平台完成。
