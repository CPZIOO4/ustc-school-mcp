学校助手 · Windows 本地应用

1. 完整解压文件夹，双击 USTC-School-Agent.exe。不要单独移走 EXE 或 _internal 文件夹。
2. 应用会在本机浏览器打开界面。在“学校身份”中打开学校官方登录窗口，完成登录与验证。
3. 在“模型与设置”选择 DeepSeek 并填写 API Key，点击“保存并测试”。其他服务选择“自定义兼容 API”，填写服务商地址和模型，可获取模型列表。
也可选择“科大大模型公共服务”，获取本人已有密钥、选择模型并绑定。没有密钥时先在学校平台申请；程序不会创建项目或申请额度。
4. 两步完成后回到对话，直接描述需求。应用按需连接学校平台。材料用输入框旁的按钮选择；发送、提交等实际办理操作按本条指令或具体预览授权。
5. 学校邮箱是可选项，用到邮件时再登录绑定。会话过期时按页面提示重新验证，再继续原任务。

本机需要 Google Chrome。Python 与程序依赖已打包，不需要手工部署 MCP。
API 使用 Chat Completions 兼容协议；服务商和模型必须支持 function calling。
登录密码不进入聊天。登录状态、模型密钥和对话等保存在 Windows 用户目录下的 USTCSchoolAgent 中；更新程序不会覆盖这些数据。
学校会话或设备信任可能失效，届时重新完成校方验证。评课社区使用独立账号。

在应用的“退出应用”中关闭后台服务。关闭浏览器标签页不会停止应用或已经安排的业务脚本。
已有后台任务时，先核实或取消任务，再切换账号或清理数据。不要删除私人目录来绕过结果未知的状态。

目前财务支持入口和材料预检，不创建报销单；选退课没有执行接口；青春科大不自动提交作品。
此应用为非官方开源项目，与学校官方网站的服务范围和可用性分别核验。

遇到错误时，到“模型与设置 → 安全日志与故障报告”查看编号、复制摘要或预览导出报告。日志不含凭据与业务正文，不会自动上传；清理日志不影响学校登录和任务回执。程序无法打开时的导出方法见随附 safety-logs.md。

新增一网通办、学工奖学金、西区图书馆空间、科大云盘和 Vlab。文件可选 PDF、图片、Excel、文本或 DOCX；可要求生成可下载文件。OCR 结果需要核对。预约/取消须具体目标，最终提交目前尚未真实验收；云盘和 Vlab 已用独立测试材料验证。
