# 第六章：107 算力任务

前五章为校园信息、学习规划、日程、提醒与材料复习，原片65秒。本章延续同一应用窗口和蓝灰色画面，新增20秒。业务素材来自本人107账号，展示既有计算作业查询和官方详情核验；不新增计算作业。

## 功能与镜头
