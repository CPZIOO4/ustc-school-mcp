# 发布范围与邮箱接入

本项目处于实验性连接与读取验证阶段。当前提供八个独立 MCP 服务，覆盖邮箱、BB、教务系统、图书馆、教务处网站、南七集市、评课社区和青春科大。各站点支持范围以适配器文档和实际工具为准，已有项目内 [学校查询 Skill](../.agents/skills/school-services/SKILL.md)。

## 源码与私人数据

仓库只发布通用代码、文档、依赖锁文件和合成测试数据。账号、客户端专用密码、统一身份密码、Cookie、信任设备、站点令牌、邮件附件、成绩及诊断页面均保留在本机私人目录，不进入 Git。加密后的凭据也不应提交；DPAPI 加密不能代替发布前排除。

`.local/` 是默认私人目录，可以通过 `SCHOOL_MCP_LOCAL_DIR` 指向仓库之外的目录。学校登录凭据和会话使用 Windows 当前用户绑定的 DPAPI 加密；邮箱地址及不含秘密的进度信息仍可能以明文保存在私人目录。因此不能直接打包整个工作目录上传。

提交问题报告时，应只提供脱敏错误和操作步骤，不附带原始网页、浏览器存储、网络抓包、邮件正文或私人目录。测试使用合成身份和合成令牌，不需要真实账号。

## 邮箱优先的配置流程

建议把邮箱作为需要自动处理邮箱二次验证的用户的第一步；公共网站查询和仍有效的学校会话无需强制绑定邮箱。

已实现不联网、不弹窗的 `school_mail_setup_guide` 和 `mail-guide` 命令，以及本机遮罩录入、只读验证后加密保存、保存失败回滚。首次网页登录、校方额外验证和新建授权由本人操作。流程不会自动打开可见 Chrome，也不自动创建、删除或重置客户端密码。详见 [邮箱接入说明](mail.md)。

网页自动创建密码、在程序内存捕获新密码并完成保存的方案仍为规划，未实现也未真实验收。本轮没有创建新认证授权。后续若实现，需先得到用户明确授权，并处理页面不匹配、配额不足、一次显示与保存失败；不能重复生成或更动其他客户端授权。

当前可用方式仍是 [手动配置邮箱](../README.md#配置邮箱)。邮箱客户端专用密码与统一身份密码是不同凭据，不能互相替代。创建客户端密码的页面流程以及首次登录要求由学校决定，不能保证所有账号只登录一次就能完成。

客户端密码的当前配额和生成要求以用户看到的 [学校官方页面](https://mail.ustc.edu.cn/notice/2fa/) 为准。页面无法核实时不推断当前名额，也不重复生成；保存失败只保留已有配置及本机加密备份。

## 后续学校认证

已有代码优先复用有效会话和信任设备。用户明确启用并绑定邮箱回退后，学校若提供匹配的可信邮箱验证方式，程序记录 UIDNEXT 后请求一次验证码，只检查边界后的学校发件人、当前收件邮箱候选；验证码由程序内部处理，不需要传给模型。页面或邮箱改变、编号变化、验证码歧义、正文截断、超时或额外验证时停止。旧版仅有布尔许可的配置须在本机明确绑定邮箱后才能继续自动邮件验证。

目前邮箱回退只适配统一身份认证站点，不代表任意网站的二次验证都可自动处理。真实邮件二次验证尚待完整验收；页面改变、邮箱不匹配、验证码歧义或图形验证时，应交由用户处理。

配套 Skill 指导模型选择工具、判断登录状态、读取适当范围的数据和解释失败原因。凭据管理、验证码匹配与权限边界由程序实现，不能仅依赖 Skill 中的文字约定。

## 发布检查与已知限制

`tests/release_privacy_check.py` 只检查暂存与未忽略的发布候选路径、凭据字面量和忽略规则，不读取私人运行文件、不输出匹配原值，也不修改 Git。检查只是启发式扫描，不等于完整安全审计。`.gitignore` 另覆盖散落的邮箱配置、DPAPI 临时与备份文件、附件、HAR、诊断目录和登录进度。

首次发布目标为 `CPZIOO4/ustc-school-mcp`，源码采用 [MIT 许可证](../LICENSE)。发布范围包含八个 MCP 适配器、学校查询与业务预览 Skill、文档和合成测试；不包含私人运行目录、认证资料、页面快照、附件或真实账号测试产物。Git 提交使用 GitHub 隐私邮箱。

2026-10-06 发布准备完成 133 项单元测试和八个真实 stdio 服务的握手、工具发现及未配置错误检查。另对发布候选做路径与凭据扫描，在本机内存中比对已保存的个人账号、密码和会话值，检查不输出或上传这些值。扫描是防护措施，不等于完整安全审计。

建议使用仓库外私人目录，并持续以合成数据维护失败路径测试。真实邮件二次验证、私人附件下载、非空借阅和网页自动引导仍有未验证范围，见 [检查记录](validation.md)。第二课堂报名和作品提交目前只有已识别路线与 Skill 说明，没有对应执行工具或真实提交验收。
