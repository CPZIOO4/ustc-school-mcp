# 分阶段查询与107实验流程验收

## 交付内容

课表与 BB 作业采用可恢复的分阶段读取。`school_study_query` 先返回课表、作业目录、来源链接和 query_id；`school_study_continue` 每次核实一项提交历史；`school_study_status` 读取保存的结果。原生应用自动继续核实，并在等待期间展示结果卡片。核实完成后卡片收起，保留最终回答和可点击来源；有待选择、失败或暂停项目时仍展开详情。

107新增准备、预检、提交、状态、取消和收集六个实验接口。实验包被冻结并计算摘要；每项实验绑定账号和唯一编号，提交使用原子认领。环境准备与训练在 Slurm 分配的节点运行。结果包含 results 目录、退出回执及日志，下载后验证字节数、SHA-256 和 ZIP CRC。

桌面聊天协调、状态投影、来源链接和文件显示继续由 Rust 核心执行。学校读取与107实验IO通过固定 Python 适配入口调用；两种客户端共享相同的账号绑定记录格式和业务实现。
