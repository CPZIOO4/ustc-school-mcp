# 邮箱首次接入与安全验证

收发邮件共用这里配置的客户端专用密码。新邮件、回复、附件发送、本机回执及线程回复查询见 [发信说明](mail-sending.md) 和 [固定操作 Skill](../.agents/skills/school-services/references/mail-workflows.md)。SMTP 操作需要用户发送授权；接入邮箱本身不授权发送。

邮件查询默认采用较小范围：搜索默认 10 封摘要、正文默认 6000 字符；收件人、抄送和线程头仅在 `include_headers=true` 时返回。连接检查不返回完整邮箱地址。限速、失败退避和详细字段规则见 [请求与数据策略](request-policy.md)，内部验证码匹配所需的邮件头不受输出精简影响。

`school_mail_setup_guide` 和 `.venv\Scripts\python.exe -m school_mcp mail-guide` 提供首次接入步骤。它们只检查本机文件是否存在，不解密密码、不联网、不弹窗；`configured_unchecked` 表示尚未验证。真实可用性以 `school_mail_check_connection` 为准。

## 本机接入

用户明确选择配置后，在项目目录运行 `python setup_mail.py`。使用支持 tkinter 的现有 Python；无需新装软件。窗口可手动打开学校网页邮箱。先由本人完成网页登录和校方验证，再将完整邮箱地址、已授权的客户端专用密码输入遮罩窗口。学校的账号密码与客户端专用密码不是同一凭据。

如需要新建客户端密码，请由本人在学校网页的“设置 → 安全设置 → 客户端专用密码”中操作，具体入口和配额以当前学校页面为准。程序不创建、删除、重置授权，不自动打开浏览器，不重复生成密码。对话中不要粘贴密码或验证码；不截图包含凭据的页面。

本机窗口先进行只读 IMAP TLS 登录与收件箱计数检查，成功后才保存 Windows 当前用户绑定的 DPAPI 凭据。验证失败保留旧配置；保存期间失败会恢复旧配置。如果进程被中断或恢复也失败，私人目录可能保留 `mail-setup-*` 加密备份，应在本机处理，不上传或重新生成授权。未保存的新密码应由本人安全保管。输入提交后清空遮罩字段；失败时需要在本机重新输入。

首次接入引导和人工录入流程已实现；网页自动创建、读取新生成密码的流程尚未实现，也未进行真实验收。

## 邮件二次验证的独立许可

邮箱接入本身不启用学校登录邮件验证。本人明确授权后，可以在配置统一身份凭据时使用 `bb-setup --email-verification`；也可保留已有凭据，仅修改许可：

```powershell
.venv\Scripts\python.exe -m school_mcp bb-email-verification --enable
.venv\Scripts\python.exe -m school_mcp bb-email-verification --disable
```

启用时将当前邮箱地址和许可一起保存到账号绑定的加密配置中；命令不请求验证码或启动登录。应先通过邮箱连接检查再启用。旧版仅保存布尔许可的配置，需要本人在本机明确启用一次以绑定邮箱；更换邮箱后也需要重新绑定。未绑定配置不会自动读取认证邮件。

已经明确授权的学校重新登录流程优先复用既有会话。校方要求验证、提供可识别邮箱方式且目标匹配时，程序先只读取得收件箱 UIDNEXT，再请求一次验证码。后续只搜索这一边界后的学校发件域、当前收件邮箱候选邮件头，最多 20 个候选；仅对符合认证主题、收件地址和统一认证语境的邮件读取正文，不读取旧邮件摘要。正文使用 `BODY.PEEK` 保留未读状态。

页面目标、配置邮箱或认证来源变化；UIDVALIDITY 变化；候选过多；邮件正文截断、验证码歧义或属于密码恢复；等待超时或学校拒绝验证码时，停止自动处理。掩码需要保留可辨认的账号字符和完整域名，完全隐藏的邮箱不能作为许可依据。验证码只在程序内存中处理，每次登录最多请求一次、提交一次，等待上限 180 秒。

需要人工操作时返回 `waiting_for_verification`，无头后台停止；只有本人明确选择人工登录才使用对应登录命令的 `--headed`。程序不绕过图形、滑块、短信验证，不自动增加持久授权。

## 验证边界

合成邮件、隔离无头 Chrome、Windows DPAPI 和 stdio 服务测试能验证程序边界，不能证明校方当前真实二次验证页面兼容。真实验证码接收与提交、真实私人附件下载仍未验收。连接冒烟仅验证现有账号的只读计数，不读取邮件正文或附件。

参考：[学校邮箱入口](https://mail.ustc.edu.cn/)；[学校二次验证说明](https://mail.ustc.edu.cn/notice/2fa/)。校方页面无法访问时，应以本机用户看到的页面为准。
