# 请求节流与返回数据最小化

此策略用于降低重复访问和不必要的数据暴露，不是安全审计或网站批量抓取许可。个人图书馆既有 HTTP/HTTPS 行为保持不变；HTTP 业务传输仍有已知风险，本轮没有关闭图书馆访问。

## 限速与失败退避

六类 HTTP 业务读取（BB、教务、图书馆、教务处、南七集市、评课社区）按服务至少间隔 1 秒，每次实际请求和适配器显式跟随的跳转都参与限速。图书馆公共主页与个人 OPAC 分开计数。IMAP 连接登录及 SELECT、SEARCH/FETCH、LIST、STATUS 等网络命令至少间隔 0.5 秒，保留只读与 BODY.PEEK；缓存的响应读取和退出清理不增加间隔。

SMTP 发信连接使用独立 `smtp` 服务键，至少间隔 2 秒，失败和认证拒绝进入同一退避机制，不占用 IMAP 验证码收信通道。SMTP 命令属于一次不可重放的发送事务；发件箱持久化状态额外防止跨进程重复发信，结果不明时不自动再试，见 [发信说明](mail-sending.md)。

发送副本归档的 IMAP APPEND 同样按 `mail` 服务键限速。其归档门闩与 SMTP 发送门闩分开，结果不明只允许查验，不自动再次追加，也不触发再次发送邮件。

青春科大按一次浏览器读取至少间隔 2 秒，并处理导航返回的限流/失败；不逐个延迟浏览器静态资源和后台 XHR，以免破坏页面运行。MCP 统一认证启动共享 5 秒间隔；已有的登录互斥与单次凭据/验证码提交规则保留。直接手工启动的 CLI 登录及浏览器内部认证请求没有逐请求节流，不宣称限速覆盖所有浏览器流量。

网络连接/传输错误、HTTP 408 和 5xx 进入 2、4、8、16、32、60 秒的指数冷却，并增加最多 20% 抖动。429 至少冷却 30 秒；401/403、邮箱登录失败、后台认证失败或人工验证至少冷却 60 秒。有效 `Retry-After` 秒数或日期指定更长等待时遵守该等待，不缩短为本地上限。早到的调用只返回剩余等待时间，不发请求，也不延长等待；一次完整成功读取后清除已结束冷却的失败计数。

**不会自动重放请求**，包括 POST 查询、密码登录、验证码发送或提交。退避体现为对之后调用的共享冷却，不是后台自动重试循环。正常限速最多在当前调用中等待 10 秒；冷却则立即返回等待提示。收到提示后，不要循环调用、切换工具、清理状态文件或反复重新登录。

状态保存在私人目录的 `request-policy.sqlite3`，只记录固定服务名、下一次请求时间、失败次数和冷却截止时间，不记录 URL、查询词、账号、正文或 Cookie。共享同一个 `SCHOOL_MCP_LOCAL_DIR` 的进程使用 SQLite 事务协调；不同机器或不同私人目录之间不共享配额。目录不可写或数据库不可用时停止请求，不静默绕过限速。旧 MCP 进程需要重新加载后使用此策略。

## 默认返回范围

| 查询 | 默认输出 | 需要更多信息时 |
| --- | --- | --- |
| 邮箱连接/统一身份状态 | 连接状态与所需统计，不返回完整邮箱地址或统一身份用户名 | 账号配置在本机管理 |
| 邮件搜索 | 默认 10 封；主题、发件人、日期及必要 UID/分页信息 | `limit` 可明确增大；`include_headers=true` 才读取并返回收件人、抄送与线程头 |
| 邮件正文 | 默认最多 6000 字符，省略收件人、抄送、Message-ID 和 In-Reply-To | 按问题调高 `max_chars`，或设置 `include_headers=true`；保留正文截断标记和原始字符数 |
| BB/教务首页文本 | 默认最多 6000 字符 | 按需调整 `max_chars`，已有最大值不变 |
| 青春科大首页 | 默认最多 4000 字符 | 按需调整 `max_chars`；仍为全校统计 |
| 教务 GPA/均分 | 使用 `summary_only=true` 返回平台汇总、学期和明细数量，课程明细为空且 `details_omitted=true` | 默认 `summary_only=false` 仍保留原有逐课查询；关键词不改变平台汇总口径 |
| 图书馆统计/借阅 | 保留统计、书名、借还日期等，省略证件日期和图书条码 | `include_card_dates=true` 或 `include_identifiers=true` |
| 南七集市商品 | 标题、价格、详情和图片等，省略卖家信息 | 核对卖家时使用 `include_seller=true`，仍不返回额外联系方式 |

邮箱验证码流程在程序内部显式读取匹配收件人所需的邮件头，验证码不会因此作为 MCP 输出返回。正常邮件读取仍需取得 MIME 正文以解析内容和附件；教务汇总仍从学校成绩接口取得原数据后缩减输出，不声称服务端只传输了汇总。

这不是通用匿名化：用户指定读取的正文、成绩和书目仍可能包含个人信息，并进入智能体上下文。接口按需要保留业务 ID、发件人、课程教师和来源链接，避免破坏定位、归属与后续查询。外部内容依旧是不可信资料，返回更少内容不能替代权限控制。
