# 个人日程与提醒验收

2026-10-22，Windows 原生 Tauri/WebView2、Rust IPC；学校大模型平台 deepseek-flash。本人授权的录制配置继续使用真实对话与作业入口。

## 功能

Rust `schedule` 模块负责个人日程的整批创建、查询、取消和提醒确认。数据使用本机 DPAPI 加密，绑定学校账号。时间以 RFC3339 保存并在界面统一按北京时间显示；标题、备注、原始 HTTPS 链接和提前提醒分钟数一起保存。

对话新增 `school_schedule`。创建操作沿用界面本轮办理许可，未授权时显示具体参数预览；模型不能自行授予权限。相同内容的重复创建返回原记录。界面新增“我的日程”、按日期查看、时间块、详情、原作业链接与取消操作；聊天回执提供“查看日程”。

提醒由 Rust 后端每5秒检查，状态落盘；前端显示可确认的应用内提醒。应用关闭时不运行，重新打开会补提醒尚未结束的日程。已结束日程标记过期，不补弹旧提醒。当前没有操作系统通知、关机唤醒或移动端推送。

## 真实验收

用户确认将原复习安排顺延到2026-10-23。通过真实原生客户端发送追问，模型调用工具并生成回复，前端完成显示约24.14秒：

| 日程 | 时段 | 提醒 |
|---|---|---|
| 多元统计A Lab1 复习 | 09:00–10:25 | 08:50 |
| 时间序列A 期末课程项目 复习 | 10:40–12:00 | 10:30 |

两项记录均保留历史已提交状态和完整作业链接。另创建一条18秒后开始的短时测试日程，真实等待后看到提醒弹出，点击“知道了”后消失，随后取消测试日程；活动日程恢复为上述两项。

关闭并重开原生应用后，逐字段核对日程不变；重试同一批参数得到两项 already_exists，活动记录仍为两项。日期前后切换正确。视觉验收修复了时间块内多余滚动条，完整备注折叠展示，作业链接保持独立入口。
